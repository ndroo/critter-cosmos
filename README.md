# Critter Cosmos

An original pocket-creature spin on the classic fixed-screen arcade formula. Defend a deep-space research outpost from colorful waves of cosmic critters.

## Play

- **Live game:** https://ndroo.github.io/critter-cosmos/
- Move with **A/D**, **arrow keys**, or the on-screen controls.
- Fire with **Space** or the **Fire** button.

## Run locally

```bash
npm install
npm run dev -- --port 3002
```

Then open http://localhost:3002.

Built with Next.js, React, TypeScript, and Canvas. The creatures and artwork are original and are not affiliated with Pokémon or Nintendo.
